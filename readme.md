# E-Commerce Sales Analysis Using SQL

## Project Overview
This project focuses on analyzing e-commerce sales data using SQL. It explores customer behavior, product performance, order trends, and revenue generation.

## Database Details
- Database: ecommerce_portfolio
- Tables: Customers, Products, Orders
- Customers: 10 records
- Products: 10 records
- Orders: 20 records

## SQL Skills Used
- SELECT, WHERE, ORDER BY
- Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- CASE WHEN
- Date Functions
- Business Data Analysis

## Business Questions
- Which products generate the highest revenue?
- Which customers spend the most?
- Which product category performs best?
- How many orders are placed each month?
- Which customers have not placed any orders?

## Tools Used
- MySQL
- MySQL Workbench
- VS Code

## Project Objective
To analyze e-commerce sales data and extract meaningful business insights using SQL.
